# 💰 Loan Calculator – Python Tkinter

A simple and user-friendly **Loan Calculator Desktop Application** developed using Python and Tkinter. This application calculates the monthly loan installment based on the loan amount, annual interest rate, and number of installments.

## 📌 Project Overview

The Loan Calculator provides an easy way to calculate monthly loan payments through a graphical user interface (GUI). Users can enter their loan details and instantly calculate the installment amount.

## ✨ Features

- 🏦 Calculate monthly loan installments.
- 💵 Enter the total loan amount.
- 📅 Specify the number of installments.
- 📊 Enter the annual interest rate.
- 🖥️ Simple and interactive graphical user interface.
- 🎨 Customized interface with Tkinter Frames, Labels, and Buttons.
- ❌ Exit button to close the application.

## 🧮 Formula Used

The application uses the standard EMI (Equated Monthly Installment) formula:

\[
EMI = \frac{P \times r \times (1+r)^n}{(1+r)^n-1}
\]

Where:

- **P** = Principal Loan Amount
- **r** = Monthly Interest Rate (Annual Rate / 12 / 100)
- **n** = Number of Monthly Installments

## 🚀 How to Use

1. Run the Python program.
2. Enter the loan amount.
3. Enter the number of installments.

6. View the calculated monthly installment.
7. Click **Exit** to close the application.
